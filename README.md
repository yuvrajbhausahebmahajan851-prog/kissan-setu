# Kisan Setu - Agricultural Logistics & Cold Storage Aggregator

Kisan Setu is a mobile web application designed to empower farmers by connecting them to nearby cold storage facilities, shared transport pooling, and intelligent crop retention decision tools.

## 🚀 Live Demo
- **App Link:** https://yuvrajbhausahebmahajan851-prog.github.io/kissan-setu/

## ✨ Key Features
- **Cold Storage Locator:** Real-time visibility into local storage hubs, rates, and temperature controls.
- **Shared Transport Pooling:** Dynamic cost-splitting logistics for regional market delivery.
- **Store-or-Sell Advisor:** Smart calculations comparing crop shelf life against market trends.
- **Offline & UPI Integrated:** Built as a single-page app with local storage persistence and mock UPI transaction handling.

## 🛠 Tech Stack
- HTML5 / CSS3 (CSS Variables, Mobile Viewport Safe Areas)
- Vanilla JavaScript (ES6+, IndexedDB, LocalStorage API)
- Deployed via GitHub Pages
